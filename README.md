# АРМ Снабженца

Курсовая работа по дисциплине «Проектирование программных средств».

## Описание

Программное обеспечение для автоматизации работы отдела снабжения предприятия. Позволяет вести реестр закупок, управлять планами закупок, контролировать складские остатки и формировать отчетность.

## Функциональность

- Работа с поставщиками (просмотр, добавление, редактирование, удаление)
- Работа с материалами (просмотр, добавление, редактирование, удаление)
- Ведение реестра закупок с детализацией по материалам
- Планирование закупок по месяцам
- Контроль складских остатков и нормативов
- Формирование отчетов:
  - Статистика по материалам
  - Материалы ниже нормы
  - Поставщики с закупками
  - Полный анализ закупок

## Технологии

- Python 3.x
- PostgreSQL
- psycopg2
- ООП-архитектура (многослойная)
